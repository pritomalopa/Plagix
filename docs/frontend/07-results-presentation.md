# Results Presentation and Comparison UI

**PLAGIX v1.0**  
**Last updated:** 21 November 2026

---

## Results Dashboard

- **Summary Cards:** Total accepted submissions, relevance breakdown, high-similarity flag count.
- **Submission Table:** Student label, relevance status badge, highest similarity risk score, suggested provisional marks, and action link.
- **Filters & Search:** Filter by relevance category, similarity severity, or search by student name/ID.

---

## Side-by-Side Comparison Viewer

- **Canonical Pair Storage:** Compares Submission A and Submission B (`sub_a_id < sub_b_id`).
- **Multi-Dimension Metrics:** Displays Exact (Winnowing), Lexical (TF-IDF cosine), and Semantic (embeddings) scores separately.
- **Passage Highlighting:** Interactive text highlighting linking matching excerpts between submissions with page/offset tracking.
- **Boilerplate Suppression:** Common question text and configured boilerplate suppressed from similarity evidence.
