# Responsive Layouts

**PLAGIX v1.0**  
**Last updated:** 21 November 2026

---

## Breakpoints (Tailwind Defaults)
- **Mobile:** `< 640px` (Stacked layout, collapsible sidebar, hamburger menu)
- **Tablet:** `640px - 1024px` (Optimized tables, grid view for cards)
- **Desktop:** `> 1024px` (Full multi-column dashboard, side-by-side comparison view)

---

## Adaptive Components
- Side-by-side comparison collapses into a tabbed toggle view on mobile screens (`< 768px`).
- Tables become horizontal scrollable containers or card lists on small viewports.
- Navigation shifts from persistent sidebar to top bar with mobile slide-out drawer.
