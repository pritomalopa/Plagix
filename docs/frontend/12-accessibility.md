# Accessibility Requirements (WCAG 2.1 AA)

**PLAGIX v1.0**  
**Last updated:** 21 November 2026

---

## Accessibility Standards

PLAGIX adheres to **WCAG 2.1 Level AA** guidelines to ensure usability for all teachers and administrators.

### Core Requirements
1. **Keyboard Navigation:** All interactive elements (buttons, links, tables, modals) must be fully navigable via keyboard (`Tab`, `Shift+Tab`, `Enter`, `Escape`).
2. **Color Contrast:** Minimum 4.5:1 contrast ratio for normal text and 3:1 for large text / UI controls.
3. **Screen Reader Support:** ARIA labels, roles, and live regions for dynamic progress updates and error messages.
4. **Focus Indicators:** Visible, high-contrast focus rings on all focused elements.
5. **Text Resizing:** Interface must remain fully functional when text size is scaled up to 200%.
6. **Semantic HTML:** Proper use of header tags (`h1`-`h6`), landmark regions (`main`, `nav`, `header`), and button elements.
